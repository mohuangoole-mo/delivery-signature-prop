# 宅配簽收道具

拍攝用的手機網頁道具，模擬宅配司機的行動簽收終端機畫面。可直接用手機瀏覽器打開，不用安裝任何 App。

## 使用方式

1. 用手機打開這個頁面（GitHub Pages 連結見下方，或直接開 `index.html`）。
2. 拍攝前先點單號、配送日期、收件人、品項四個欄位，改成這場戲要用的內容。
3. 演員在簽名區用手指簽名。
4. 按「確認簽收」會出現簽收完成畫面（含簽名縮圖）。
5. 要再拍一次，按「清除並重新簽收」就能回到空白狀態。

## 線上連結

啟用 GitHub Pages 後會是：
`https://<你的帳號>.github.io/delivery-signature-prop/`

## 技術說明

單一 `index.html`，純 HTML／CSS／JavaScript，沒有依賴套件，手機瀏覽器開啟即可用。簽名用 Canvas 繪製，不會上傳到任何伺服器，單純是拍攝現場的道具畫面。
